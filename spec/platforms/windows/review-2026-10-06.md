# Design review of the Windows mapping, 2026-10-06

Superseded in part: the turn-on-encryption, password-check and forgot-password pages it reviews were removed or replaced in 1.1 (the encrypt-journals pages no longer exist because version 1.1 supports no unencrypted libraries; see [change-password](screens/change-password.md)).

An independent design agent reviewed this whole folder (`README`, `platform`, `commands`, the copy proposals, `index`, `messages`, every screen and flow file) against the platform-neutral spec, the open questions D20 to D53 and Microsoft's guidance, as [AGENTS.md](../../../AGENTS.md) requires before implementation. It was given the requirements and the proposal, not the author's defence. This file records the outcome: the verdict, and for every finding whether it was **adopted**, **changed** (adopted with a different detail, said here) or **declined** (with the reason). Where a finding concerns an owner decision (D20 to D53), the decision was not made here: the question's drafted default now follows the reviewer's recommendation where the reviewer gave a reason, the recommendation is recorded in the question, and the mapping files follow the drafted default.

## Verdict

The mapping is unusually thorough and mostly well grounded. The shell (`TitleBar`, `NavigationView`, Mica), Settings as `SettingsCard` pages, `InfoBar` notices, one dialog at a time, sentence case and the ellipsis rule, Windows Hello through the desktop interop, DPAPI behind `ISecretStore`, clipboard-history exclusion and Windows-safe file names all match Microsoft guidance. It was **not yet ready to hand to implementation**: the editor plan was built on a control that failed several of its own Must requirements, the privacy cover was a Mac behaviour transplanted into an environment where windows lose focus all day, the heading shortcuts broke AltGr typing, formatting lived in a flyout where Windows uses a bar, and App Lock had a lock-out hole with a platform constraint (Windows 11) stated as a recommendation. The review found 10 must fix, 17 should fix and 14 consider items, and 11 contradictions. All are resolved below.

## Claims no document settles

The review could not verify these from documentation; each is a first-build test ([platform.md, 34](platform.md#34-open-questions)): Alt access and drag regions of a `MenuBar` inside the `TitleBar`; accelerator routing while `RichEditBox` or a `ContentDialog` has focus; the capabilities `DnssdServiceWatcher` needs for a packaged full-trust app; how `RichEditBox` applies the system text scale to character formats; Remote Desktop behaviour of `UserConsentVerifier`. The Notepad formatting update is cited from a news report, not Microsoft documentation.
